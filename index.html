Tweakable Values Demo

How @tweakable Works

The @tweakable annotation is a special comment that marks values that can be adjusted by users without needing to modify code directly.

For example, in this demo, the circle and square properties are tweakable:

/* @tweakable the size of the circle */
const circleRadius = 50;

/* @tweakable the color of the circle */
const circleColor = "#ff5252";

/* @tweakable the size of the square */
const squareSize = 80;

/* @tweakable the color of the square */
const squareColor = "#4285f4";

When you run this in a supported environment, these values would get UI controls automatically generated, allowing easy adjustments without editing code.
