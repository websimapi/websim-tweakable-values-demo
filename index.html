Tweakable Values Demo

The Power of @tweakable

The @tweakable annotation is a special comment that marks values that can be adjusted by users without needing to modify code directly. This creates a powerful and immediate feedback loop between design and implementation.

In this enhanced demo, you can tweak:

  • Basic properties: Size, color, and animation duration for shapes
  • Border styles: Thickness, color, and style (solid, dashed, dotted)
  • Shadow effects: Blur amount and color
  • Particle system: Count, size range, and animation speed
  • Animation effects: Pulse intensity and timing

Example of Tweakable Values:

/* @tweakable the size of the circle */
const circleRadius = 50;

/* @tweakable border thickness for shapes in pixels */
const borderWidth = 3;

/* @tweakable shadow blur amount in pixels */
const shadowBlur = 10;

/* @tweakable number of particles in background */
const particleCount = 15;

/* @tweakable pulse effect intensity (0-1) */
const pulseIntensity = 0.2;

When you run this in a supported environment, these values would get UI controls automatically generated, allowing for experimentation and fine-tuning without editing code.

This example demonstrates how @tweakable can transform simple static elements into a dynamic, interactive design system that bridges the gap between code and design.
